# Seller Dashboard Application

A modern, responsive Next.js [Frontend] application for managing orders, inventory, earnings, customer messages, and multiple stores. Built with Redux for state management, TailwindCSS for styling, and Recharts for data visualization.

## Features

### Pages
- **Dashboard** - Overview of orders, sales metrics, and weekly performance
- **Inventory** - Product management with search, filtering, and stock tracking
- **Earnings** - Financial analytics with revenue charts and transaction history
- **Chat** - Customer messaging system with conversation history
- **Stores** - Enterprise store management for multi-store operations
- **Settings** - Account preferences and configurations

### Design System
- **Color System**: Cyan (#00BCD4) primary, Pink (#E91E8C) secondary, with green/orange/red status indicators
- **Typography**: Geist font family with consistent hierarchy
- **Components**: Reusable UI primitives, cards, badges, and layout components
- **Responsive**: Mobile-first design with desktop sidebar and mobile bottom navigation
- **Charts**: Interactive area and line charts using Recharts
